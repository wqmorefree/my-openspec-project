# ADR-007：导入导出——EasyExcel 导入 + CSV 流式导出

## 状态
已采纳

## 背景
需支持批量导入（Excel）与列表导出（CSV）。要求：导入须校验数据合法性（必填、编码唯一，含文件内去重）并给出失败明细；导出按当前筛选条件，且空结果不生成空文件。

## 选项

| 选型 | 优点 | 缺点 |
|------|------|------|
| Apache POI 手写解析 | 完全可控、无框架依赖 | 代码量大、DOM 模式内存占用高（大数据量易 OOM）、重复造轮子 |
| EasyExcel（阿里） | RuoYi-Vue-Plus 自带、注解式映射、流式解析省内存、支持逐行回调校验 | 需遵循其注解/监听器约定，复杂报表样式支持弱（本项目仅简单导入） |
| CSV 导出（流式输出） | 按当前筛选查询即流式输出、浏览器直接下载、零第三方依赖 | 无样式、字段需手工转义逗号/引号 |

## 决策
选择 EasyExcel 做导入、流式输出做 CSV 导出。

## 理由
- EasyExcel 是框架自带依赖，零新增引入，与 RuoYi-Vue-Plus 集成自然，省去 POI 模板代码。
- 考虑导入大数据量时内存安全，EasyExcel 基于流式解析，优于 POI 整表加载。
- 导入校验在解析回调中逐行完成（必填、编码唯一含文件内去重），可精确返回"成功/失败明细"，符合 specs 对导入场景的验收要求。
- CSV 导出按当前筛选条件查询后流式写出，响应头触发下载；空结果时提示不生成空文件，避免误导性下载。
- 范围对齐：本 change 导入仅支持"新增"（不做更新/合并），与首个切片交付范围一致。
